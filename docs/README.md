# Documentação

Este diretório contém dois conjuntos de documentação, com públicos distintos.

## `dev/`

Documentação de desenvolvimento: arquitetura, contratos, convenções de
trabalho e conhecimento acumulado do projeto. É a documentação consultada
pelos agentes de código (Claude Code, Codex, etc.) para construir a Ana.

## `system/`

Documentação de sistema: será a documentação que a própria Ana consulta e
utiliza em tempo de execução. Ainda não elaborada.
