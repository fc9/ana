# Skill

> Conceito futuro. Fora do escopo do MVP.

Representa um conjunto reutilizável de instruções para executar uma
tarefa específica.

### Responsabilidades (futuro):

- definir comportamento e contexto para uma tarefa específica
- declarar quais Tools está autorizada a usar
- ser utilizável pelo Core e por Agents

### Não deve:

- executar código diretamente (isso é responsabilidade das Tools)
- tomar decisões (isso é responsabilidade dos Agents/Core)
