# Task

> Conceito futuro. Sem aplicação prática no MVP.

Representa uma atividade agendada pelo usuário, relacionada a um
projeto.

### Responsabilidades (futuro):

- pertencer a um único projeto
- possuir agendamento (quando deve ser executada)
- possuir status de execução

### Não deve:

- pertencer a mais de um projeto
- conter lógica de negócio complexa (a execução é responsabilidade de
  outro módulo/agente)
