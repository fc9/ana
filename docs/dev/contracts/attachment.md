# Attachment

Representa um arquivo, imagem, texto ou conteúdo de clipboard enviado pelo
usuário.

### Responsabilidades:

- pertencer a um único chat
- possuir tipo (arquivo, imagem, texto, clipboard)

### Não deve:

- pertencer a mais de um chat
- pertencer a uma mensagem específica (anexos pertencem ao chat, não à
  mensagem)
- conter lógica de IA
