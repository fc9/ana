# Message

Representa uma mensagem dentro de um chat.

### Responsabilidades:

- pertencer a um único chat
- possuir remetente (usuário ou Ana)
- possuir conteúdo e data

### Não deve:

- pertencer a mais de um chat
- conter lógica de IA
- armazenar anexos (anexos pertencem ao chat, não à mensagem)
