# Project Expenses

> Conceito futuro. Sem aplicação prática no MVP.

Representa o controle de gasto de tokens de um projeto, por modelo
utilizado.

### Responsabilidades (futuro):

- pertencer a um único projeto
- registrar consumo de tokens por Provider/modelo
- permitir consulta de custo acumulado por projeto

### Não deve:

- pertencer a mais de um projeto
- conter lógica de cobrança (apenas registro/consulta)
